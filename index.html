A browser tab cannot reach the Tor network on its own — there's no such thing as "Tor from HTML." This field only points Buddie at a bridge you run locally (e.g. a small script proxying through Tor's SOCKS port), same pattern as the scraper endpoint above, kept separate and under its own hard rules:
• Only fires when you tap the 🧅 Tor toggle next to the search bar — off by default, never turns itself on.
• Sends your typed query terms exactly as written — no expansion, no related-topic guessing.
• Text only. Buddie strips markup and keeps plain text; it never fetches, follows, or saves images, video, binaries, or file downloads of any kind, from this endpoint or any other.
• Every result is scanned by a built-in explicit-content filter before it touches storage. Anything flagged is discarded immediately — only a "blocked" note is logged, the flagged text itself is never kept, shown, or written anywhere.
• Nothing from this endpoint is auto-saved. Results land in a separate review queue (Memory tab) and only enter Pre-Verified if you personally tap "Keep" on that specific item.
You're responsible for what your own bridge script does and for the legality of using it where you live — Buddie's part is limited to the rules above.
